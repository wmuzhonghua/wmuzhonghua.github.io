## 项目概况

参考 https://nehsgnail.github.io/cv/ 及其主页、Research、Project 页，独立编写四页个人学术网站。以简洁排版、Claude 风格的暖米白与陶土色、半透明导航、响应式布局、明暗主题和鼠标交互粒子为主要视觉特点。个人内容已依据用户提供的《卢忠华_简历整理.md》整理，包含教育经历、环境健康研究、软件成果、参与课题及荣誉。

## 参考站的实现分析

2026-11-04 直接读取公开页面 HTML：

- generator 标签为 Astro v7.1.0；页面内样式标记为 Tailwind CSS v4.3.3。
- 路由包括 `/`、`/research/`、`/project/`、`/cv/`，页面带 Astro 编译标记，研究及项目页含交互岛。
- 共用固定导航、页脚、CSS 主题变量；主题模式包括跟随系统、浅色和深色，并由 localStorage 保存。
- CV 是居中的单栏简历，包含教育、研究经历、技能、荣誉和联系信息。页面含复制邮箱脚本。
- 背景包含 SVG 和 canvas 星点元素；主页介绍个人身份与研究兴趣，研究页展示论文，项目页展示项目与仓库入口。
- GitHub API 将其公开仓库描述为 GitHub Pages deployment；未读取到原始开发源码，不能仅由编译产物确认完整开发流程。

本项目采用 Astro 7.4.5（项目自带 Node 22.23.4，npm 脚本会优先使用，不修改系统 Node）和原生 CSS，自行实现版式与交互。未复制作者的照片、论文图片或个人资料；装饰插图为本地 CSS 绘制。未复现参考站的全部动画细节。

## 本地运行

```sh
npm install
npm run dev
```

访问终端输出的本机地址（默认 http://127.0.0.1:4321）。

```sh
npm run build
npm run preview
```

构建产物位于 `dist/`，为静态文件，无需后端数据库。
